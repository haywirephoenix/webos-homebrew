haywire's webOS apps

A Homebrew Channel repository for rooted LG webOS TVs. In Homebrew Channel, open Settings, choose Add repository and enter:

https://haywirephoenix.github.io/webos-homebrew/apps.json

  • Local Voice: speech recognition that runs on the TV.
  • Tailscale: install, update and run Tailscale on the TV. Not affiliated with Tailscale Inc.

Both need root. Built for and tested on an LG BX with webOS 5.4.
